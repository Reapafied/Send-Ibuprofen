# Send Ibuprofen - WoW Horde Live Sync Bingo

A real-time, interactive World of Warcraft Horde-themed Bingo board built with React, Vite, Tailwind CSS, and Firebase Realtime Database.

## Features
- **Real-Time Live Sync**: Connect your Firebase Realtime Database to sync stamps across all player cards and devices dynamically.
- **Seeded Randomization**: Unique, deterministic 5x5 card shuffling based on player seed IDs.
- **Synthesized Audio**: Web Audio API sound triggers for stamping squares and winning BINGO lines.
- **Print High-Contrast Mode**: Built-in CSS print styles stripping dark backgrounds for physical paper cards.

## Deployment & Setup

1. Enable GitHub Pages under **Settings -> Pages** in your repo and select **GitHub Actions** as the source.
2. Push your changes to the `main` branch to trigger auto-deployment!
